# Gym sprites

Drop room-tier images here named exactly:

```
r0.png   r1.png   r2.png   r3.png   r4.png   r5.png
```

Specs and prompt templates: see `visualizer/docs/sprite-spec.md`.

If a file is missing the renderer falls back to the SVG backdrop for that
tier, so you can populate this folder one room at a time.
