# Lobster sprites

Drop tier-specific images here named exactly:

```
t0.png   t1.png   t2.png   t3.png   t4.png
t5.png   t6.png   t7.png   t8.png   t9.png
```

Specs and prompt templates: see `visualizer/docs/sprite-spec.md`.

If a file is missing the renderer falls back to the SVG sprite for that tier,
so you can populate this folder one tier at a time.
